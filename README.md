# Mini ERP - Hệ thống Quản trị Doanh nghiệp thu nhỏ

## Giới thiệu
Hệ thống Mini ERP gồm các phân hệ: Nhân sự, Kho hàng, Kế toán nội bộ, CRM, phân quyền RBAC.

## Công nghệ
HTML/CSS/JavaScript, PHP thuần (MVC), MySQL (XAMPP).

## Cấu trúc thư mục
- setup: tập tin cài đặt, dữ liệu thử nghiệm
- src: mã nguồn
- progress-report: báo cáo tiến độ
- thesis: tài liệu đồ án (doc, pdf, html, abs, refs)
- soft: phần mềm liên quan (nếu có)
- docker: tập tin triển khai docker (nếu có)

## Hướng dẫn chạy
1. Bật Apache và MySQL trong XAMPP.
2. Import src/database/schema.sql vào MySQL.
3. Truy cập http://localhost/mini-erp/src/public
